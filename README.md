# Tholi Bag Builder

Prompt Start

Build a single-product landing page for a women's crossbody bag. This is a product-focused page — no brand story, no multi-page shop. Just one bag, multiple colors, and an order form. The goal is to convert visitors (mostly from Facebook/Instagram ads) into buyers.

Product Details

Product name: Geometric Knot Crossbody Bag

Brand: Tholi (থলি)

Pricing:

১টি ব্যাগ = ৳700

২টি ব্যাগ = ৳1,300 (combo deal — customer saves ৳100)

Available colors (6): Black (কালো), Nude Beige (বেইজ), Olive Green (অলিভ), Rose Mauve (রোজ), Chartreuse / Lime Yellow (লাইম), Soft Pink (পিংক)

Material: Premium PU Leather with embossed geometric pattern on the flap

Handle: Knotted top handle with gold-tone metal tips on both sides

Strap: Detachable & adjustable long crossbody strap included

Closure: Magnetic flap with tonal square buckle detail at center

Dimensions: Approx. 22cm (L) × 14cm (H) × 7cm (W)

Weight: ~350g

Interior: 1 main compartment + 1 inner zip pocket

Hardware: Gold-tone metal tips and buckle

Delivery: Inside Dhaka ৳60, Outside Dhaka ৳120

Payment: Cash on Delivery only

Delivery time: Dhaka 2–4 days, Outside Dhaka 3–5 days

Return: 3-day return if unused & in original packaging

Design Direction

Target audience: Bangladeshi young women (18–30), mobile-first, coming from social media ads

Tone: Trendy, fun, youthful, trustworthy — NOT luxury or minimal. Think polished Instagram shop aesthetic

Primary color: Vibrant orange (#FF6B35) — matches the brand logo

Background: Warm white (#FFF8F0) with very light peach (#FFF0E6) section alternation

Text color: Deep charcoal (#2D2D2D)

Accent: Soft coral (#FF8C69), gold (#C9A96E) for premium touches

Typography: Bold rounded sans-serif headings (Nunito Bold or Poppins Bold), clean body text (Inter or Poppins Regular)

Language: Mix of Bangla (বাংলা) and English — headings mostly Bangla, technical specs in English

Mobile-first: 85%+ visitors will be on mobile. Design mobile layout first, then adapt for desktop

Image handling: Use clearly labeled placeholder boxes for all images — I'll upload real product photos after generation

Responsive:

Mobile-first design (85%+ traffic will be mobile)

Scroll-triggered fade-in / slide-up on each section (subtle, not heavy)

Success message: checkmark + confetti

Sticky bottom bar: slide up on first scroll

Tailwind CSS

Warm, light theme — no dark mode

Rounded corners everywhere (8–16px)

Soft shadows on cards

No heavy libraries — keep it fast loading

Lazy load images (when real ones are added)
